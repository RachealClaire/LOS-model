# 🏥 Hospital Length of Stay (HLOS) Prediction Model

## Overview

The **HLOS model** is a machine learning–based tool developed to predict the length of hospital stay for patients using routinely collected clinical and demographic data. It is designed to support clinical decision-making, improve hospital resource allocation, and enhance overall healthcare efficiency.

---

## 🚀 Features

* Predicts patient hospital length of stay
* Uses a simple set of input variables for ease of use
* Supports early identification of high-risk patients
* Can be integrated into hospital systems or used independently
* Designed for resource-limited healthcare settings

---

## 📊 Input Variables

The model uses the following six features:

* Referral status
* Hospital site
* Age
* Antimicrobial resistance profile
* Number of comorbidities
* Number of infection sites

---

## ⚙️ How It Works

The model is trained on historical patient data and learns patterns associated with hospital stay duration. When new patient data is provided, it generates a prediction of expected length of stay based on these learned relationships.

---

## 👥 Intended Users

* Clinicians (doctors, nurses, clinical officers)
* Hospital administrators and managers
* Public health professionals and policymakers
* Researchers and data scientists
* Health economists and insurance providers

---

## 💡 Use Cases

* Patient risk stratification at admission
* Hospital bed and resource planning
* Monitoring and improving healthcare efficiency
* Supporting antimicrobial resistance (AMR) research

---

## ⚠️ Limitations

* Model performance depends on data quality
* Requires validation before use in new settings
* Does not capture all possible clinical factors influencing hospital stay
* Should be used as a decision-support tool, not a replacement for clinical judgment
